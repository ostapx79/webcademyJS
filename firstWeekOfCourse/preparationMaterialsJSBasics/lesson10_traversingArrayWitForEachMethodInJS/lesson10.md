### 10 Обход массива методом for each в JavaScript
```javascript
// Создаем массв
var fruits = ["Banana", "Apple", "Peach", "Pineapple", "Chery"];

// Обход массива функции forEach
fruits.forEach((item, index) => {
    console.log(`Элемент ${item} имеет индекс ${index}`);
});
```
